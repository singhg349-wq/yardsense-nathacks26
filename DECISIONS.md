| 23 | Nov 7 | **Map idle counts follow the what-if schedule.** New `POST /assets/available` accepts the same shifts as `/plan`; the GET route stays for the baseline | Closes the known gap in #16. The map's moves already updated on drag; now the idle KPI, fleet card and site idle lists do too. |
| 24 | Nov 8 | **Min-cost is a PuLP/CBC static assignment comparison, not the live plan.** The live plan stays greedy; the comparison reports the exact gap on the same request snapshot. It is a static snapshot (no relocation re-pricing, buy only when no unit is free), so it is not presented as a replacement engine. |
| 25 | Nov 8 | **Re-plan suggestion (`GET`/`POST /replan`, Timeline card) is suggestion-only.** Requests that have already started (start on or before the demo date) are locked to their greedy choice; the rest are re-solved with the existing PuLP/CBC min-cost model. Each changed request pays a switching cost: one extra truck move (same transport cost function) if a unit was due to move, otherwise an assumed flat $150 admin/cancellation fee (`SWITCH_FEE` in `replan_suggestion.py`). Recommends only when net saving = greedy - re-plan - switching is positive | Shows the gap is worth closing net of the cost of changing bookings, without making the live plan depend on the static model. The live plan stays greedy (see #24): it re-prices relocation and lets purchases create units, which the static model does not, and planners need choices that do not reshuffle on every what-if. The $150 fee is a placeholder, not sourced. |
| 26 | Nov 8 | **Fleet advisor prices each extra unit on its own marginal demand, net of owning cost, against group-wide supply** (replaces #20). Supply = every group company's units minus units on open-ended outside hire in the check-out log. The k-th extra unit only covers days when more than supply + k - 1 units are needed at once; rent avoided is outside rental plus delivery for those day runs. Net annual impact = rent avoided - (one year of depreciation + 12 months of maintenance and insurance). Add only when net > 0; break-even = purchase price / monthly net saving, or "doesn't pay back". Retire only units idle today and surplus to peak. When the live plan buys a class the advisor would not add, the reason says so and gives one unit's net | The old rule credited the whole class pipeline to one unit, so break-even was always month 1 and every add lost money over the year (e.g. the 5th boom covers 26 days, $3,950 saved against $21,240 to own). It also counted only NR01 units and ignored outside hire, so it retired compactors that were all on hire and said "hold" on generators the plan was buying. The math stays inside `fleet_advisor.py`; the per-request buy test in `cost_model.py` is unchanged here |
| 27 | Nov 8 | **The live plan can split a multi-unit need.** It fills as many units as it can from the cheapest idle units (move ours / rent from sister, mixed if cheaper), then covers only the rest with rent outside or buy. Buy is allowed for the rest only once every idle unit is used, the same rule as a single option. The split is a fifth option, `"split"`, with a `units` list (one entry per source: option, qty, costs, reason, assets, moves); it is offered only when it is cheaper than every single-source option. Every plan row also gains `units`; existing fields keep their meaning. The Requests screen shows it as "1 × Move ours + 1 × Buy" | Before, a need for 2 units with 1 idle made every internal option unavailable, so Whitemud rented 2 telehandlers and 2 boom lifts outside ($142,940) while one of each sat idle. Splitting uses the idle unit and costs $31,845 for both needs. The live plan now costs $56,762, below the static min-cost model's $123,646, because that model only allows buy for a unit request with no candidate unit and does not reuse purchased units; its assumptions list says so. The Riverside recommendations and the Kingsway what-if (generator buy → rent outside, five changes) are unchanged |
